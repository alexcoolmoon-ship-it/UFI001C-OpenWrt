# UFI001C OpenWrt v3.2.9 — упрощённая установка

Дата: 2026-10-23. Профиль: clean. Базовый образ: OpenWrt 25.12.5 (ядро 6.12.94).

Прошивка та же, что в v3.2.8 (NTP через Яндекс, DNS через туннель
с выбором своего DNS, списки и пакеты через туннель при блокировке
прямого доступа). Изменения только в упаковке USB-комплекта.

## Что изменилось

1. **Два файла — два сценария, двойной клик.** Больше не нужно ничего
   вводить в cmd вручную:
   - `INSTALL.cmd` — первая прошивка стокового модема (EDL, бэкап,
     проверка, запись). Как раньше.
   - `UPDATE.cmd` — обновление уже прошитого модема. Бэкап находится
     автоматически в папке `UFI001C-backups` (берётся самый свежий),
     путь вводить не нужно. Переписываются только rootfs и boot,
     NV и GPT сверяются с бэкапом.
2. **Плоский ZIP.** Файлы лежат в корне архива, без подпапки
   `UFI001C-{VERSION}/`. Распаковал — запустил нужный .cmd.
3. **Инструкция в TXT.** `INSTALL-RU.txt` вместо `INSTALL-RU.md`:
   plain text, два сценария, без ручных команд.

## Обновление с v3.2.8

Скачайте USB-ZIP из этого релиза, распакуйте, дважды кликните
`UPDATE.cmd` и следуйте подсказкам. Сохраните свою прокси-ссылку
отдельно перед обновлением.

## Проверки

- [ ] INSTALL.cmd на стоковом модеме
- [ ] UPDATE.cmd на прошитом модеме
- [ ] Wi-Fi пароль из ACCESS.txt, интернет через Podkop

# Установка и обновление UFI001C

Актуально для комплекта **v0.0.1** и новее. Нужен **полный USB-ZIP
успешной сборки** для Windows 10/11 x64, а не архив исходников:
в нём уже лежат образы, переносимый установщик, Python-окружение, EDL
и USB-библиотека. Устанавливать Python, Git или EDL отдельно не нужно.

Скачивание и проверка комплекта — страница релизов:

https://github.com/alexcoolmoon-ship-it/UFI001C-OpenWrt/releases

SHA256 скачанного ZIP сверяйте с файлом `.zip.sha256` рядом с релизом:

```cmd
certutil -hashfile UFI001C-OpenWrt-25.12.5-v0.0.1-USB.zip SHA256
```

Распаковывайте ZIP **целиком в отдельную пустую папку**, не поверх
старого комплекта: папки сольются, и установщик может подхватить файлы
от другой версии.

## Заводской модем (установка с нуля)

Подробная инструкция — в
[migration/README-STOCK-RU.md](migration/README-STOCK-RU.md).
Коротко: `INSTALL.cmd` → модем в EDL с зажатой кнопкой → проверка
разметки и радио до любой записи → полный бэкап → подтверждение →
запись boot и system с обратным чтением → переподключение без кнопки,
2–3 минуты первого запуска, Wi-Fi из `ACCESS.txt`, панель
http://192.168.1.1.

Без драйвера Qualcomm для режима EDL (QDLoader 9008) установщик
не увидит модем: `INSTALL.cmd` сам проверит драйвер, а при его
отсутствии подскажет установить его через `tools\DRIVER-HELP.cmd`
(файлы драйвера — в `tools\drivers\`, см. `tools\DRIVER-RU.txt`).

## Уже установленный OpenWrt (обновление)

Для модема, на котором уже стоит OpenWrt, используйте **`UPDATE.cmd`**
из нового комплекта. `INSTALL.cmd` для этого случая не предназначен.

Что делает UPDATE.cmd:

1. **Бэкап не нужен и не используется.** Пути вводить не нужно.
   Бэкапы нужны только для возврата модема к стоку (`RESTORE.cmd`).
2. Просит подключить модем в EDL (с зажатой кнопкой, затем отпустить).
3. Проверяет живую GPT модема (обязана быть раскладкой OpenWrt),
   живой boot-образ и непустоту NV, затем переписывает
   **только boot и system** с обратным чтением каждого участка.
   Радио-раздел не трогается.

Что важно знать заранее:

- **Rootfs ставится начисто**: настройки, пароль root, пароль Wi-Fi
  и секции Podkop сбросятся к значениям нового комплекта.
  **Сохраните заранее свою прокси-ссылку и все свои настройки** —
  после обновления их придётся ввести заново.
- **Без бэкапа нет отката к текущему состоянию**: обновление
  перезатирает boot и system, а вернуться к тому, что было до него,
  без заранее сделанного бэкапа нельзя. Стоковый бэкап от установки
  с нуля для отката после обновления тоже не подойдёт — он
  возвращает заводскую прошивку, а не текущее OpenWrt.
- Штатного обновления из веб-панели LuCI у этой сборки нет:
  обновление — только через `UPDATE.cmd` в EDL.

Шаги обновления:

1. Распакуйте новый ZIP в пустую папку.
2. Запустите `UPDATE.cmd`, следуйте подсказкам, дождитесь проверки
   обратным чтением.
3. Переподключите модем без кнопки, подождите 2–3 минуты.
4. Подключитесь к Wi-Fi из `ACCESS.txt` нового комплекта, откройте
   http://192.168.1.1, задайте пароль root.
5. Вставьте SIM, проверьте LTE (интерфейс `modem`, регистрация,
   технология LTE), затем введите свою прокси-ссылку в Podkop →
   Секции, сохраните и запустите Podkop.

Если обновление прервалось до начала записи — просто запустите
`UPDATE.cmd` заново. Если прервалось во время записи — переподключите
модем в EDL и выполните возврат к стоку через `tools\RESTORE.cmd`
из полного `emmc.bin`, затем повторите обновление.

## Откат обновления

Откат — это возврат к стоку, а не к предыдущей версии OpenWrt:
`tools\RESTORE.cmd` → свой `emmc.bin` → модем в EDL → ввести `RESTORE`.
После отката модем снова станет заводским, и для OpenWrt его нужно
будет прошить заново через `INSTALL.cmd`.

## Настройка Podkop после установки или обновления

Откройте Podkop → Секции, введите **свою** прокси-ссылку, сохраните
и запустите Podkop. По умолчанию включён DoH 1.1.1.1 с bootstrap
через Яндекс, сервис-прокси включён, списки качаются через туннель:
Яндекс используется только для резолва адреса прокси, весь остальной
DNS — только через туннель.

Аппаратный профиль LTE: B1/B3/B5/B8/B38/B39/B40/B41. Диапазонов
**B7/B20 у этого модема физически нет** — софтом их не включить.

## Если что-то остановилось

Сохраните текст ошибки и папку запуска из
`%USERPROFILE%\UFI001C-backups`. Полный дамп с NV не публикуйте:
в нём IMEI и индивидуальные данные модема. Не отключайте USB
и не выключайте ПК во время записи.

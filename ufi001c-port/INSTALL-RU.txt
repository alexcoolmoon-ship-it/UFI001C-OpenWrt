================================================================================
 УСТАНОВКА UFI001C v3.2.8 Clean
================================================================================

Нужен полный архив UFI001C-OpenWrt-25.12.5-v3.2.8-USB.zip из успешной сборки,
не архив исходников. Распакуйте целиком в отдельную папку.

--------------------------------------------------------------------------------
 ВАРИАНТ 1: ЗАВОДСКОЙ МОДЕМ (первая прошивка)
--------------------------------------------------------------------------------

1. Распакуйте архив целиком, например в C:\ufi001c\
2. Запустите INSTALL.cmd и следуйте подсказкам:
   - Переведите модем в EDL (зажать кнопку при подключении)
   - Дождитесь полного бэкапа
   - Подтвердите модель UFI001C
   - Дождитесь завершения прошивки
3. Если драйверы не встали — один раз запустите DRIVER-HELP.cmd

Python и EDL-утилиты уже в комплекте, ничего ставить не нужно.

--------------------------------------------------------------------------------
 ВАРИАНТ 2: ОБНОВЛЕНИЕ (уже стоит OpenWrt)
--------------------------------------------------------------------------------

Сохраните свою прокси-ссылку отдельно! Новый rootfs ставится начисто.

1. Распакуйте архив, например в %USERPROFILE%\openwrt25-v3.2.8\
2. Оставьте подключённым ОДИН модем, переведите его в EDL
3. Откройте CMD и выполните бэкап:

   cd /d "%USERPROFILE%\openwrt25-v3.2.8"
   "%USERPROFILE%\edl\.venv\Scripts\python.exe" ufi-install.py backup --images "%USERPROFILE%\UFI001C-backups"

4. После надписи BACKUP VERIFIED скопируйте полный путь к свежему emmc.bin
5. Выполните обновление:

   "%USERPROFILE%\edl\.venv\Scripts\python.exe" ufi-install.py update --images . --backup "ПУТЬ_К_EMMC.BIN"

6. Дождитесь UPDATE VERIFIED
7. Переподключите модем БЕЗ кнопки

Обновляются только rootfs и boot. Ваши NV-данные и GPT сверяются с бэкапом.

--------------------------------------------------------------------------------
 НАСТРОЙКА PODKOP
--------------------------------------------------------------------------------

1. Откройте http://192.168.1.1 в браузере
2. Задайте пароль root при первом входе
3. Откройте Podkop -> Секции
4. Введите свою прокси-ссылку, сохраните
5. Включите и запустите Podkop

DNS:
  - Тип: DNS через HTTPS (DoH)
  - Сервер: 1.1.1.1 или 8.8.8.8 (идёт через туннель)
  - Bootstrap: 77.88.8.8 (Яндекс, только для резолва имени прокси)

Время синхронизируется автоматически через Яндекс NTP при старте Podkop.

--------------------------------------------------------------------------------
 ПРОВЕРКА
--------------------------------------------------------------------------------

После прошивки проверьте:
  [ ] Открываются сайты
  [ ] Работает видео
  [ ] Диагностика Podkop — все пункты зелёные
  [ ] После перезагрузки питания всё работает
  [ ] Через 30 минут нагрузки — без отвалов

Версия сборки: cat /etc/ufi001c-release

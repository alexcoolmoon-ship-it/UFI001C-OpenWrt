Установка UFI001C v3.2.9 Clean
============================

Нужен полный UFI001C-OpenWrt-25.12.5-v3.2.9-USB.zip из успешной сборки,
не архив исходников. Распакуйте целиком в любую папку.
Файлы лежат в корне, без подпапок. ACCESS.txt содержит пароль Wi-Fi.

Два файла — два сценария. Ничего вводить в cmd не нужно,
просто дважды кликните нужный файл и следуйте подсказкам.


ЗАВОДСКОЙ (стоковый) МОДЕМ — первая прошивка
--------------------------------------------
Дважды кликните INSTALL.cmd

Что будет: EDL-режим с зажатой кнопкой, полный бэкап,
проверка совместимости, подтверждение UFI001C, обратное чтение.
Python и EDL уже включены в комплект.
Если модем не виден — один раз запустите DRIVER-HELP.cmd
(поставит драйвер через Zadig).
Подробности в README-STOCK-RU.md.
Поддержаны только точные известные профили 4/8 ГБ.


УЖЕ ПРОШИТЫЙ МОДЕМ — обновление
--------------------------------
Дважды кликните UPDATE.cmd

Бэкап находится сам (папка UFI001C-backups), путь вводить не нужно.
Обновляются только rootfs и boot; NV и GPT сверяются с бэкапом.
Дождитесь UPDATE VERIFIED, переподключите модем без кнопки.


Настройка Podkop
----------------
Откройте http://192.168.1.1, задайте пароль root.
В Podkop -> Секции введите свою ссылку, сохраните, включите и запустите.
В Podkop -> Настройки -> DNS Server можно выбрать DNS или вписать свой —
любой DNS идёт через туннель, Яндекс 77.88.8.8 используется только
для имён прокси (bootstrap).
Сохраните свою прокси-ссылку отдельно. Старый /etc/config/podkop
целиком не восстанавливайте.
Профиль LTE: B1/B3/B5/B8/B38/B39/B40/B41, без B7/B20.

Проверьте сайты, видео и DNS после перезапуска питания.
Номер сборки: cat /etc/ufi001c-release

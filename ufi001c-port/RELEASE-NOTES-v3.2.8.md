# UFI001C OpenWrt v3.2.8 — исправление интеграции Podkop

Дата: 2026-10-21. Профиль: clean. Базовый образ: OpenWrt 25.12.5 (ядро 6.12.94).

## Что исправлено

1. **DNS клиентов теперь всегда идёт через туннель.** Раньше `dnsmasq_configure`
   пропускал настройку после любого некорректного выключения (а флаг
   `shutdown_correctly` по умолчанию 0 — то есть на свежей прошивке dnsmasq
   **никогда** не настраивался на Podkop-DNS 127.0.0.42). Клиенты резолвили через
   DNS оператора мимо туннеля, получали реальные IP, и их трафик не попадал под
   правила nftables — отсюда «интернет не работает» и нулевые счётчики.
   Теперь функция идемпотентна: при каждом старте сверяет фактическое состояние
   и приводит его к нужному; бэкап оригинальных настроек делается один раз.
2. **Диагностика policy routing больше не врёт.** Проверка искала правило по
   номеру таблицы (`lookup 105`), а установщик регистрирует её по имени
   (`lookup podkop`) — статус был вечно красным при рабочем роутинге.
3. **Устранены гонки старт/стоп/рестарт** (файл-блокировка с защитой от
   зависшего лока): раньше параллельные операции могли оставить расколотое
   состояние «nft-таблица есть, policy routing снесён, sing-box работает».
4. **Идемпотентное создание nft-правил**: таблица пересоздаётся, дубли правил
   при повторных стартах исключены; в конце проверяется наличие цепочек
   mangle/mangle_output/proxy, ошибки прерывают старт, а не дают
   полурабочее состояние.
5. **`ip rule` больше не дублируется**: проверка существования правила теперь
   учитывает нормализацию hex (`0x100000` вместо `0x00100000`).
6. **`remove_cron_job` больше не затирает весь crontab root**, если его не было.
7. **Проверка DHCP** учитывает только основную секцию dnsmasq (гостевые сети
   больше не красят диагностику в красное).
8. **Убрана несуществующая команда `podkop main`** (была в help, функции не было).
9. **Остановка по ошибке**: если не удалось удалить nft-таблицу, стоп прерывается
   с ошибкой вместо молчаливого раскола; PID фонового `list_update` проверяется
   по `/proc/<pid>/cmdline` перед kill.

## Обновление

Как обычно: распаковать USB-архив, прошить через EDL/stock_install.py.
`platform_check_image` по-прежнему отклоняет sysupgrade из LuCI.

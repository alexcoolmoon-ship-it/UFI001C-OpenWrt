# Проверка v0.0.1

Дополнительно к проверкам v3.2.14: путь обновления без бэкапа.

## Что проверено

- `update_firmware()` больше не ищет `backup-*/emmc.bin` и не
  запускает `ufi-install.py` отдельным процессом (под замороженным
  exe этот путь не работал: exe получал `ufi-install.py` как
  действие и падал в argparse, а `ufi-install.py` требует
  `.venv/edl.py`, которого в комплекте нет). Обновление теперь
  выполняется внутри установщика классом `EDL` — тем же, что
  установка и восстановление, включая проверку portable runtime
  в `EDL.__init__`.
- Перед любой записью обновление читает живую GPT и требует
  точную раскладку OpenWrt из `ufi-install.EXPECTED` (порядок
  разделов, старты, размеры, кроме rootfs, который расширен
  до конца диска при установке). Стоковая GPT отклоняется
  сообщением «Stock/unknown GPT conversion is NOT supported
  by update» — это тот же отказ, что и раньше, но теперь
  до записи, а не после поиска бэкапа.
- Живой boot-образ проверяется `check_boot()` (ANDROID!,
  cmdline с root=/dev/mmcblk0p14, ядро ARM64), якоря NV
  (modemst1/modemst2) — на непустоту. Пишутся только boot
  и rootfs, каждый участок — через `execute_plan()` с обратным
  чтением; при несовпадении подсказка теперь — повторить
  `UPDATE.cmd` без перезагрузки, а не `RESTORE.cmd`.
- Новые тесты `UpdateWithoutBackupTests` в
  `test_stock_install.py`: успешное обновление без бэкапа
  (пишутся только boot и rootfs, журнал
  `written-and-readback-verified`), отказ на стоковой
  разметке, отказ на невалидном живом boot и отказ на пустом
  NV-якоре — в каждом отказе записей ноль.
- Юнит-тесты комплекта: полный набор, 0 падений (проверено
  локально на коммите перед запуском сборки).
- Версия комплекта перезапущена: `VERSION = '0.0.1'` в
  установщике, `ufi001c-release`, профиль rootfs, workflow,
  ZIP, тег релиза и инструкции — везде 0.0.1. Манифест
  portable runtime штампуется из той же версии, поэтому
  проверка runtime в `EDL.__init__` остаётся консистентной.
- Аппаратная приёмка: первый прогон `UPDATE.cmd` из комплекта
  0.0.1 на живом уже прошитом модеме — открытая проверка,
  её результат определит, закрыта ли нить обновления без бэкапа.

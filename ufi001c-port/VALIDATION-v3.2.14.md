# Проверка v3.2.14 Clean

Дополнительно к проверкам v3.2.11: проверка portable runtime.

## Что проверено

- `verify_portable_runtime()` в `runtime_manifest.py` проверяет
  только то, что доступно замороженному установщику: версию
  манифеста, smoke-тесты и полный инвентарь файлов runtime.
  Проверка source-хешей здесь намеренно не используется: она
  требует дерева migration (INSTALL.cmd и др. лежат в корне
  комплекта, а не в tools/), и в замороженном контексте дала бы
  ложный отказ.
- `EDL.__init__` вызывает проверку до первой команды EDL, то
  есть до подключения модема и чтения GPT. Несовпадение —
  ValueError, который main() превращает в STOP без записи.
- Новые тесты `test_portable_edl_refuses_other_version_and_modified_runtime`
  падают, если проверка снова исчезнет; существующий тест
  команды EDL переведён на полный fixture runtime с манифестом.
- Юнит-тесты комплекта: полный набор, 0 падений (проверено
  локально на коммите перед запуском сборки).
- Прошивка и остальные файлы комплекта — как в v3.2.11,
  изменены только версия, проверка runtime, тест-сторож
  и файлы релиза/валидации.

# UFI001C: установка с нуля (заводской модем → OpenWrt)

Актуально для комплекта **v3.2.14** и новее. Если у вас уже стоит OpenWrt —
вам не сюда, а в [INSTALL-RU.md](../INSTALL-RU.md) (обновление через UPDATE.cmd).

Нужен **полный USB-ZIP успешной сборки** для Windows 10/11 x64, а не архив
исходников. В нём уже лежат образы, переносимый установщик, Python-окружение,
EDL и USB-библиотека. Устанавливать Python, Git или EDL отдельно не нужно.
Интернет во время прошивки не используется.

## Что нужно

1. Модем **UFI001C**. Проверьте маркировку платы, а не только корпус:
   одинакового корпуса недостаточно.
2. Windows-ПК с USB-портом. К ПК должен быть подключён **только один модем**.
3. Свободное место на диске: не менее **12 ГБ** (полный бэкап 4–8 ГБ плюс
   место под подготовку образов и их проверку).
4. Драйвер Qualcomm для режима EDL (см. раздел про драйвер ниже).

## Шаг 1. Скачайте комплект

Откройте страницу релизов репозитория:

https://github.com/alexcoolmoon-ship-it/UFI001C-OpenWrt/releases

Скачайте файл вида `UFI001C-OpenWrt-25.12.5-v3.2.14-USB.zip`
(для v3.2.14 — релиз `ufi001c-v3.2.14-52-1`).

Сверьте SHA256 скачанного файла с файлом `.zip.sha256` рядом с релизом.
В командной строке Windows:

```cmd
certutil -hashfile UFI001C-OpenWrt-25.12.5-v3.2.14-USB.zip SHA256
```

Несовпадение хеша — не прошивайте, скачайте файл заново.

## Шаг 2. Распакуйте в пустую папку

Распакуйте ZIP **целиком в отдельную пустую папку**. Не распаковывайте
поверх старого комплекта: папки сольются, и установщик может подхватить
файлы от другой версии.

После распаковки в корне папки должны быть `INSTALL.cmd`, `UPDATE.cmd`,
`ИНСТРУКЦИЯ.txt`, а всё остальное — в папке `tools\`.

## Шаг 3. Драйвер EDL (один раз на ПК)

Для прошивки модем переводится в сервисный режим EDL
(Qualcomm HS-USB QDLoader 9008). Без драйвера Windows не видит модем
в этом режиме, и установщик не сможет подключиться.

`INSTALL.cmd` при запуске сам проверяет драйвер: ищет Qualcomm среди
установленных драйверов или устройство 9008 среди подключённых. Если
драйвер найден — установка идёт дальше, ничего делать не нужно.

Если драйвера нет, установщик остановится с инструкцией. Тогда:

1. Положите файлы драйвера (`.inf`, `.cat`, `.sys`) в папку `tools\drivers\`.
   Где взять драйвер — см. `tools\DRIVER-RU.txt`: QPST / Qualcomm USB Driver
   либо драйвер из пакета производителя модема.
2. Запустите `tools\DRIVER-HELP.cmd` **от имени администратора** — он
   установит драйвер через `pnputil`.
3. Переподключите модем с зажатой кнопкой (режим EDL).

Проверка: в Диспетчере устройств должно появиться
«Qualcomm HS-USB QDLoader 9008 (COM...)», либо в командной строке:

```cmd
pnputil /enum-devices /connected | findstr 9008
```

## Шаг 4. Запустите INSTALL.cmd

Запустите `INSTALL.cmd` из распакованной папки и следуйте подсказкам:

1. Когда попросят — выключите модем, **зажмите кнопку**, подключите
   к USB ПК и отпустите кнопку. Это вход в EDL (9008). Нажмите Enter.
   На этом этапе выполняется **только чтение**, записи ещё нет.
2. Установщик прочитает GPT и сверит её с известным заводским профилем,
   затем проверит радио — тоже до любой записи. Поддерживаются точные
   заводские разметки 8 ГБ, 4 ГБ и 4 ГБ + 80 МБ, а также известные хеши
   радио. Неизвестная разметка или неизвестное радио — это безопасная
   остановка: **запись не началась, модем не тронут**. Сохраните текст
   ошибки и файл `edl.log` из папки запуска.
3. Установщик спросит, делать ли полный бэкап заводской памяти
   (по умолчанию — да, `[Y/n]`). Бэкап читается блоками по 32 МБ
   и занимает около 10 минут. **Не отказывайтесь от бэкапа без
   необходимости**: без него полный откат на сток будет невозможен.
   Бэкап и журнал сохраняются в `%USERPROFILE%\UFI001C-backups\папка-запуска`.
   **Храните всю папку.** Заводские индивидуальные NV берутся только
   с этого экземпляра, чужой бэкап для отката не подойдёт.
4. После проверки бэкапа установщик покажет найденный профиль и попросит
   подтверждение — `Продолжить? [y/N]:`. Только после него начнётся запись.
5. Записываются только boot и system, GPT меняется последней. Каждый
   записанный участок читается обратно и сверяется. **Во время записи
   не отключайте USB и не выключайте ПК.**
6. Об успехе установщик сообщит строкой «ЗАПИСЬ И ЧТЕНИЕ ОБРАТНО СОВПАЛИ»
   и откроет `ACCESS.txt`.

Если отказаться от бэкапа, прочитаются только маленькие NV-разделы
для переноса настроек, прошивка займёт около минуты, но
откат через `RESTORE.cmd` станет **невозможен**.

## Шаг 5. Первый запуск

1. Отключите USB и включите модем **без зажатой кнопки**.
2. Подождите 2–3 минуты первого запуска.
3. Подключитесь к Wi-Fi из `ACCESS.txt` (по умолчанию сеть
   `OpenWrt-25-UFI001C`, пароль `1234567890` — если `ACCESS.txt`
   говорит иначе, верен он).
4. Откройте панель **http://192.168.1.1**. При первом входе root без
   пароля — **задайте свой пароль сразу** (System → Administration).
5. Вставьте SIM. Первое включение модема в ModemManager может дать
   сброс подсистемы модема (`THIS IS INTENTIONAL RESET`) — это норма
   платформы MSM8916, а не ошибка: ModemManager восстанавливается сам
   примерно за минуту, со второй попытки модем поднимается.
6. Проверьте LTE: в панели должен появиться интерфейс `modem` с IP,
   регистрация в сети и технология LTE. Для свежего отчёта запустите
   `tools\CHECK-LTE.cmd` — он ничего не меняет, только проверяет
   текущую загрузку и открывает папку с `ufi-postboot-report.tar.gz`.

Аппаратный профиль LTE: B1/B3/B5/B8/B38/B39/B40/B41. Диапазонов
**B7/B20 у этого модема физически нет** — софтом их не включить,
потолок скорости в конкретной локации от этого и зависит.

## Шаг 6. Настройка Podkop

1. В LuCI откройте Podkop → Секции, введите **свою** прокси-ссылку
   в секцию, сохраните и запустите Podkop.
2. По умолчанию включён DoH 1.1.1.1 с bootstrap через Яндекс, сервис-прокси
   включён, списки качаются через туннель. Архитектура такая: Яндекс
   используется только для резолва адреса прокси, весь остальной DNS —
   только через туннель.
3. Проверьте, что открываются и обычные сайты, и сайты, требующие туннеля.
   Если Podkop не стартует или сайты через туннель не открываются —
   пришлите лог Podkop из панели (Podkop → Диагностика) и текст ошибки.

## Если установка прервалась

- **До начала записи** (обрыв чтения бэкапа): переподключите **тот же**
  модем в EDL и запустите `tools\RESUME.cmd`, выбрав `backup-state.json`
  из сохранённой папки запуска. Уже проверенные блоки повторно не читаются.
  Частичный `emmc.partial` готовым бэкапом не считается.
- **Во время записи**: не запускайте RESUME. Переподключите модем в EDL
  и выполните возврат к стоку (см. ниже) из полного `emmc.bin`.
- При любой остановке сохраните текст ошибки и папку запуска из
  `%USERPROFILE%\UFI001C-backups`. Полный дамп с NV **не публикуйте**:
  в нём IMEI и индивидуальные данные модема.

## Возврат к стоку

Запустите `tools\RESTORE.cmd`, выберите **свой** `emmc.bin`,
подключите этот модем в EDL. После проверки принадлежности копии
введите `RESTORE`. Восстанавливается весь дамп с последующим полным
чтением обратно. Чужой бэкап и бэкап от другого модема отклоняются.

## Проверка без записи

- `tools\STOCK-CHECK.cmd` — только читает разметку и радио модема,
  ничего не пишет. Отчёт — `stock-probe.json`.
- `tools\CHECK-BACKUP.cmd` — проверяет уже сохранённый `emmc.bin`
  без USB и создаёт небольшой `ufi-stock-radio.zip`.
- `tools\CHECK-PC.cmd` — проверяет комплект на ПК без подключения модема.

## Что в папке tools\

| Файл | Назначение |
|---|---|
| `INSTALL.cmd` | Установка с нуля (сток → OpenWrt) |
| `UPDATE.cmd` | Обновление уже прошитого модема (см. INSTALL-RU.md) |
| `RESUME.cmd` | Продолжить прерванный бэкап |
| `RESTORE.cmd` | Вернуть заводскую прошивку из `emmc.bin` |
| `STOCK-CHECK.cmd` | Проверка модема без записи |
| `CHECK-BACKUP.cmd` | Проверка сохранённого бэкапа |
| `CHECK-LTE.cmd` | Отчёт о текущей загрузке модема |
| `CHECK-PC.cmd` | Проверка комплекта на ПК |
| `DRIVER-HELP.cmd` | Установка драйвера Qualcomm из `tools\drivers\` |
| `DRIVER-RU.txt` | Инструкция по драйверу |
| `RUN.cmd` | Запуск установщика вручную |
| `MAKE-BUNDLE.cmd` | Сборка такого ZIP из прошивки (для разработчиков) |

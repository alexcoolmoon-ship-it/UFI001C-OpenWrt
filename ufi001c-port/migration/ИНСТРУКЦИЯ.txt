UFI001C — прошивка модема с заводской на OpenWrt
==============================================

Что нужно
---------
1. Модем UFI001C (проверьте маркировку платы, не только корпус).
2. Windows-ПК с USB-портом.
3. Драйвер Qualcomm (режим EDL 9008). Проверка и установка —
   автоматически при запуске INSTALL.cmd (см. tools\DRIVER-RU.txt).

Как прошить (первый раз)
------------------------
1. Распакуйте этот ZIP в отдельную папку.
2. Запустите INSTALL.cmd.
3. Ответьте на вопросы:
   - делать ли полный бэкап (займёт ~10 минут; без него откат невозможен);
   - подтверждение записи (y/N).
4. Когда попросят: выключите модем, ЗАЖМИТЕ кнопку, подключите к USB,
   отпустите кнопку. Это режим EDL.
5. Дождитесь окончания. В конце откроется ACCESS.txt.

Доступ после прошивки
---------------------
Wi-Fi:     OpenWrt-25-UFI001C
Пароль:    1234567890
Панель:    http://192.168.1.1/  (root без пароля, задайте свой)
Данные для входа также лежат в ACCESS.txt из этого архива.

Что в папке tools\
------------------
RESUME.cmd      — продолжить прерванный бэкап (выбрать backup-state.json)
RESTORE.cmd     — вернуть заводскую прошивку из полного бэкапа emmc.bin
STOCK-CHECK.cmd — проверить модем без записи (отчёт stock-probe.json)
MAKE-BUNDLE.cmd — собрать такой ZIP из прошивки (для разработчиков)
RUN.cmd         — запуск установщика вручную
DRIVER-HELP.cmd — установить драйвер Qualcomm из tools\drivers\
DRIVER-RU.txt   — инструкция по драйверу

Важно
-----
- Во время записи не отключайте USB и не выключайте ПК.
- Полные бэкапы хранятся в %USERPROFILE%\UFI001C-backups — не удаляйте их.
- Флаг --no-backup (INSTALL.cmd спросит сам) пропускает полный бэкап:
  прошивка займёт ~1 минуту, но откат будет невозможен.
